## Instalación

1. Clona el repositorio:
```bash
   git clone https://github.com/RodrigoLRGH/AW_PlataformaDeCursos
```


2. Entra a las carpeta del proyecto:
```bash
   cd plataforma-cursos-backend
   cd plataforma-cursos-frontend
```

3. Instala las dependencias:
```bash
   npm install
```
